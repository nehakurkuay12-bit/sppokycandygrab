# SPOOKY CANDY GRAB

made by me (ur favorite programmer)

## what is this

its a halloween game i made in p5.js!! u are a ghost and u have to eat all the candy corn in the graveyard. but there are BATS and they will hurt u. dont let them touch u!!

## how to play

- move with the **arrow keys** or **WASD**
- grab ALL the candy to beat the level
- dont touch the bats (u only get 3 lives so be careful)
- click the game before u start or the keys wont work (idk why, its a browser thing)

## levels

there are 5 levels and they get harder each time:

| level | whats new |
|-------|-----------|
| 1 | easy. 2 bats. u got this |
| 2 | more bats and more candy |
| 3 | the **evil green ghost** shows up and CHASES u 😱 |
| 4 | faster bats, faster ghost |
| 5 | final level. good luck lol |

if u beat level 5 u win and become the candy king/queen

## how to run it

1. save the code as `index.html`
2. double click it to open in ur browser
3. u need internet bc it loads p5.js from the internet

or use the p5.js web editor (editor.p5js.org) and paste just the javascript part into `sketch.js`

## stuff u can change

if the game is too hard (or too easy) change these at the top of the code:

- `spd = 4` how fast u move
- `lives = 3` how many lives u get
- `maxLevel = 5` how many levels there are
